# requirements-lock.txt -- the exact package set a release of Oshiire ships.
#
# What: every package requirements.txt pulls in, pinned to the versions the
# app is developed and tested with (Python 3.14, Windows). Platform markers
# come from each package's own Requires-Dist (pythonnet/clr_loader are the
# Windows pywebview backend; colorama is Windows-only for click/tqdm/typer).
#
# How it was produced: `pip freeze --all` of the development venv (.venv-win),
# minus pip and the dev-only chain from requirements-dev.txt (playwright, pyee,
# greenlet, fonttools), plus those markers. tools/build_release.py installs it.
#
# Install with --no-deps. That is deliberate: dghs-imgutils still declares
# numpy<2, which has no wheel for Python 3.13+ (pip would build an experimental
# MinGW numpy that crashes on import -- see install.bat). numpy 2.x is pinned
# below and works with it. With --no-deps the pin is simply not consulted.
#
# Three packages have no Python 3.14 wheel and are built from source by the
# release workflow (SOURCE_ONLY in tools/build_release.py): bchlib,
# proxy_tools, sgmllib3k. Everything else installs --only-binary=:all:.
#
# Regenerate: in a venv where `pip install -r requirements.txt` followed by
# `pip install --upgrade numpy` works and the tests pass, run
#     python -m pip freeze --all
# then drop pip, playwright, pyee, greenlet and fonttools, and re-add the three
# markers above (re-check them by walking the Requires-Dist closure).
